16진수 색상 읽는 법
#RRGGBB 형식 — 각 2자리가 Red / Green / Blue 값 (00~FF = 0~255)
예) #FF0000 = 순수 빨강 / #00FF00 = 순수 초록 / #0000FF = 순수 파랑
세 값이 같으면 회색 계열 (#888888), 모두 00이면 검정, 모두 FF면 흰색
